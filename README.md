# platformer-for-team

Чтобы получить проект с GitHub:

1. Скопируйте ссылку на репозиторий на GitHub: кнопка Code → HTTPS → Copy.
2. Откройте VS Code.
3. Нажмите Ctrl + Shift + P.
4. Напишите Git: Clone и выберите эту команду.
5. Вставьте скопированную ссылку.
6. Выберите папку, в которую хотите скачать проект.
7. Откройте скачанный проект в VS Code.
