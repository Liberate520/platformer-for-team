# platformer-for-team

Чтобы получить проект с GitHub:

1. Скопируйте ссылку на репозиторий на GitHub: кнопка Code → HTTPS → Copy.
2. Откройте VS Code.
3. Нажмите Ctrl + Shift + P.
4. Напишите Git: Clone и выберите эту команду.
5. Вставьте скопированную ссылку.
6. Выберите папку, в которую хотите скачать проект.
7. Откройте скачанный проект в VS Code.

для работы над задачей:

1. Переходим в основную ветку git switch master
2. Обновляем ветку git pull origin master
3. Создаем ветку под задачу git switch -c <название ветки>
4. Выполняем задачу
5. Добавляем файл для отслеживания в гит git add <название файла>
6. Делаем коммит git commit -m"что сделал"
7. Пушим на гитхаб git push origin <название ветки>
8. Переходим на сайт гитхаба и создаем PR в мастер ветку
9. Двигаем стикер на доске miro
